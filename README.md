web-based application designed to streamline institutional operations and manage university data efficiently. This system provides separate functionalities for students, faculty, and administrators to interact with university resources seamlessly.
Core Features
User Authentication: Secure login profiles for students, professors, and administrators.
Student Portal: View course schedules, attendance records, final grades, and fee statuses.
Faculty Dashboard: Manage student enrollment, mark attendance, and input exam grades.
Admin Control Panel: Manage course creations, department assignments, and user accounts.

Tech Stack
Frontend: HTML5, CSS3 (for clean, responsive user interfaces and dashboard layouts).
Backend: PHP (handles server-side logic, session management, and form processing).
Database: MySQL (relational database management system for secure data storage).
